Loop to Swarm

Start from a single model call. Build up one layer at a time: the agent loop, tools, reasoning, context and memory. Then the harness that keeps an agent dependable, and finally many agents spawning and coordinating with each other. How the concepts stack

Each layer adds the minimum needed to fix a limit of the layer below it. A model can't act, so an agent loop adds tools. An agent forgets and drifts, so context and memory are managed. An agent fails, leaks and costs money, so a harness adds control, limits and visibility. One agent can't hold a big problem, so several are coordinated. Your swarm harness sits at the top and depends on every layer below it.

How to study a chapter

This guide is built for the loop in docs/LEARNING_PLAYBOOK.md. Reading without predicting first is how a week of study turns into nothing you can recall.

  1. PredictAnswer the amber Predict box in docs/LEARNING_NOTES.md before you read. Wrong answers are the point: they show you what to read carefully.
  2. Read with a penAfter each section, close it and redraw its main figure from memory. Labels count; boxes alone don't.
  3. Check yourselfAnswer every question at the end before you open it. Mark the ones you missed and reread only those sections.
  4. Explain it backExplain the chapter aloud, without notes. Only then tick “I can explain this”. The count above tracks it.
  5. Go to the sourceRead at least one primary source from the chapter's list. The guide is a map. The papers and docs are the territory.
